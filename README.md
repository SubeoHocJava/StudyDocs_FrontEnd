# StudyDocs

**StudyDocs** is a Flutter-based mobile application that allows users to share study materials, lecture notes, and documents.  
The app provides a collaborative platform where students can upload, download, comment, like, and save documents for later use.  

---

## Features

- **Upload & Share** study documents and lecture notes
- **Save & Download** documents for offline use  
- **Advanced Search** – find documents faster  
- **Comment & Like** on shared documents  
- **Favorites** – mark important documents  
- **User Profile Management** – edit personal info
